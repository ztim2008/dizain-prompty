Промпт

Ты опытный веб-дизайнер и фронтенд-разработчик. Сверстай адаптивный лендинг в стиле «Bento grid».

Стиль: Контент разложен по прямоугольным плиткам разного размера, как в коробке бенто. Каждая плитка — одна мысль.
Палитра: #F5F5F7 (фон), #1D1D1F (текст), #0A84FF (акцент), #FFD60A (плитка-акцент).
Шрифты: Inter, Manrope, Onest. Подключи шрифты локально (woff2) с поддержкой кириллицы.
Правила стиля: CSS grid с плитками 1x1, 2x1, 1x2, 2x2; gap 16px; radius 24px; плитки белые на светло-сером фоне, 1–2 плитки цветные; в каждой плитке заголовок, короткий факт или цифра и иконка/визуал; на мобильном одна колонка.

Структура страницы:
1. Шапка: логотип, меню из 4 пунктов, кнопка действия.
2. Первый экран: заголовок H1 до 8 слов, подзаголовок, основная и вторичная кнопки, визуал.
3. Преимущества: 3–6 карточек с иконкой, заголовком и одной строкой текста.
4. Услуги или тарифы с ценами.
5. Отзывы или кейсы.
6. Частые вопросы (аккордеон).
7. Форма заявки: имя, телефон, согласие на обработку персональных данных (152-ФЗ).
8. Подвал с контактами.

Требования: семантичный HTML5, mobile-first, контраст по WCAG AA, состояния :hover и :focus-visible, без внешних CDN, все тексты на русском. Выдай один файл index.html со встроенными CSS и JS.
Сделай код для HTML-блока Тильды (блок T123) в стиле «Bento grid».

Палитра: #F5F5F7 (фон), #1D1D1F (текст), #0A84FF (акцент), #FFD60A (плитка-акцент). Шрифты: Inter, Manrope, Onest (если шрифта нет в Тильде, используй системный аналог).
Правила стиля: CSS grid с плитками 1x1, 2x1, 1x2, 2x2; gap 16px; radius 24px; плитки белые на светло-сером фоне, 1–2 плитки цветные; в каждой плитке заголовок, короткий факт или цифра и иконка/визуал; на мобильном одна колонка.

Ограничения Тильды:
- весь CSS внутри <style>, все классы с префиксом .dp- чтобы не конфликтовать со стилями Тильды;
- не используй глобальные селекторы body, html, *, h1;
- JS только чистый, внутри <script>, обёрнутый в IIFE;
- ширина блока 100%, контент по центру до 1200px; адаптив под 980, 640 и 480px;
- ссылки на кнопках оставь как # с комментарием, куда подставить попап Тильды (#popup:form).

Блок: первый экран с заголовком, подзаголовком, кнопкой и тремя карточками преимуществ. Тексты на русском.
Создай в Figma дизайн лендинга в стиле «Bento grid» (десктоп 1440 и мобайл 390).

1. Сначала заведи Local Styles: цвета #F5F5F7 (фон), #1D1D1F (текст), #0A84FF (акцент), #FFD60A (плитка-акцент); текстовые стили H1/H2/H3/Body/Caption на шрифтах Inter, Manrope, Onest.
2. Эффекты: CSS grid с плитками 1x1, 2x1, 1x2, 2x2; gap 16px; radius 24px; плитки белые на светло-сером фоне, 1–2 плитки цветные; в каждой плитке заголовок, короткий факт или цифра и иконка/визуал; на мобильном одна колонка.
3. Сетка: 12 колонок, поля 120 px на десктопе; 4 колонки, поля 16 px на мобайле.
4. Компоненты с вариантами: Button (primary/secondary, default/hover/disabled), Card, Input, Header.
5. Все фреймы на Auto Layout, отступы кратны 8.
6. Экраны: первый экран, преимущества, услуги с ценами, отзывы, FAQ, форма, подвал.
